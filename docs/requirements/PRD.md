# MuseGen - 需求文档

## 1. 项目概述
构建一个纯前端的 Web 应用，允许用户上传 MP3 音频文件，自动分析并生成三档难度（入门/普通/进阶）的卡林巴琴乐谱，支持在查看器中切换难度，并支持播放合成的卡林巴音频。用户可以自定义卡林巴配置（17键/21键/自定义）。所有用户数据仅在本地缓存，不上传服务器、不做跨端同步；允许接入外部资源。

### 1.1 范围与约束
- **离线要求**：不要求完全离线可运行；允许加载外部资源，但用户上传音频与生成结果仅本地处理与缓存。
- **输入限制**：最大音频时长 10 分钟；最大文件大小 50MB；超出限制需明确提示并拒绝处理。
- **MVP 算法范围**：以主旋律（monophonic）提取为主；和弦/复音识别作为进阶目标放到最后里程碑。
- **存储策略**：统一使用 IndexedDB 存储（设置、乐谱、音频/中间结果），并提供轻量缓存层以降低重复计算。

## 2. 核心功能需求

### Phase 0: 基础设施
- **任务管理**：统一任务状态机（idle/queued/running/succeeded/failed/canceled）。
- **进度反馈**：统一进度事件协议，支持阶段、百分比、耗时估计展示。
- **取消机制**：支持 UI 触发取消，Worker 停止并释放资源。
- **错误处理**：统一错误模型，区分可恢复/不可恢复错误，提供清晰用户文案。

### Phase 1: 设置与初始化
- **卡林巴配置**：
  - 支持 17 键 / 21 键预设切换。
  - 支持自定义琴键数量和调音（每个琴键的音符设置）。
  - 配置持久化存储（IndexedDB）。

### Phase 2: 音频上传与预处理
- **文件上传**：支持 MP3 文件拖拽上传。
- **输入校验**：
  - 校验文件格式（MP3）。
  - 校验时长（<10分钟）和大小（<50MB）。
- **基础信息**：支持输入标题和可选元数据。

### Phase 3: 音频分析
- **音高检测**：使用 FFT/YIN 等算法提取主旋律。
- **音符映射**：将频率映射到用户配置的卡林巴琴键，处理超出音域的音符。
- **节奏分析**：检测节拍起始点，估算 BPM，进行音符量化。

### Phase 4: 难度生成
- **多难度生成**：一次处理生成三档难度（入门/普通/进阶）。
- **难度策略**：
  - **入门**：低密度（40%），单音，4分音符量化，9键音域。
  - **普通**：中密度（70%），简单和弦（最多2音），8分音符量化，13键音域。
  - **进阶**：高保留度，保留原始音符和复杂节奏，全17键音域。
- **缓存机制**：生成结果存入 IndexedDB 避免重复计算。

### Phase 5: 乐谱渲染与交互
- **可视化渲染**：使用 SVG 渲染数字记谱法，显示琴键编号和小节。
- **交互功能**：
  - 支持在查看器中实时切换难度。
  - 播放时高亮当前音符。
  - 响应式布局适配。

### Phase 6: 播放与导出
- **音频合成**：使用 Tone.js 合成逼真的卡林巴音色（支持 ADSR、力度）。
- **播放控制**：支持播放/暂停/停止，进度跳转，速度调节（0.5x - 2x）。
- **导出功能**：
  - PNG 图片导出（乐谱）。
  - MIDI 文件导出。
  - WAV/MP3 音频导出。

### Phase 7: 本地存储管理
- **乐谱库**：列表显示历史乐谱，支持搜索、过滤和删除。
- **存储管理**：监控存储空间，提供缓存清理策略。

## 3. 风险管理

| 风险 | 触发信号 | 潜在影响 | 缓解/应对策略 | 降级方案 |
|---|---|---|---|---|
| 主旋律提取准确率不足 | 回归集指标下降、用户反馈“跑调/漏音” | 生成乐谱不可用，返工调参 | 标准音频集回归；置信度阈值+离群值滤波；可视化调参面板（内部） | 降低输出密度、提高量化网格、只输出高置信度音符 |
| 性能/卡顿（长音频） | 处理时间超阈值、页面无响应 | 体验差、浏览器崩溃 | Worker 分块处理；可取消；进度反馈；缓存避免重复处理 | 限制最大时长/采样降频；仅分析片段 |
| 内存占用过高 | 大音频解码后内存飙升 | 崩溃/标签页被杀 | 及时释放 AudioBuffer；TypedArray；分块；IndexedDB 中间结果落盘 | 更严格时长限制；提示用户拆分 |
| 浏览器兼容问题 | Safari/移动端音频API行为差异 | 部分用户不可用 | 早期兼容性冒烟测试；关键API做能力检测与兜底 | 降级关闭部分导出/可视化；提示最低版本 |
| MP3 导出不稳定/质量差 | 编码失败或音质差、体积过大 | 导出功能不可用 | WAV 作为可靠基线；MP3 作为增强；对外明确“实验性”标识 | 仅导出 WAV |
| IndexedDB 配额/异常 | 存储失败、配额不足提示 | 无法缓存、数据丢失感 | 存储空间监控；缓存清理策略；失败时提示与重试 | 仅内存缓存本次会话，不落盘 |
| 外部资源可用性 | CDN/第三方资源加载失败 | 页面功能受限 | 资源版本锁定与兜底镜像；加载失败提示与重试 | 提示用户刷新/更换网络；关闭对应功能 |
| 版权/合规 | 用户上传受版权保护内容 | 合规风险 | 明确本地处理说明；上传区免责声明；不做跨端同步 | 重复提示，提供“我已确认”勾选 |

### 产品提示与免责
- 上传区域需显示：“音频仅在本地处理与缓存，不上传服务器；请确保你有权使用该音频进行分析与生成”。

## 4. 验证计划

### 4.1 功能测试
1. **设置测试**：预设切换、自定义配置、保存加载。
2. **上传测试**：文件大小/格式限制、取消上传。
3. **难度选择测试**：生成三档难度、验证差异。
4. **处理测试**：不同风格音乐、音符准确性、节奏量化。
5. **存储测试**：乐谱CRUD、缓存机制、空间限制。
6. **导出测试**：PNG/MIDI/音频导出质量。
7. **播放测试**：播放控制、速度调节、音符同步、音色。

### 4.2 回归测试
- 维护“标准测试音频集”，每次里程碑验收进行回归测试。
- 指标：音高命中率、起音 F1、BPM 误差。

### 4.3 性能测试
- 30秒音频处理 < 10秒（基准：桌面端 i5-8th 或同级）。
- 3分钟音频处理 < 60秒（基准：桌面端 i5-8th 或同级）。
- 内存占用 < 500MB。
- 首次加载 < 3秒。

### 4.4 兼容性测试
- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+。

## 5. 里程碑规划
- **Week 4**: 音频处理管道完成（提取音符）。
- **Week 7**: 三难度生成完成（生成可用乐谱）。
- **Week 10**: MVP完成（含UI和存储）。
- **Week 14**: 完整功能发布（优化和测试完成）。
