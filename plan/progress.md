- 插画与装饰

  - 背景装饰层增加若干气泡/星点，响应式位置与性能优化（减少频繁重绘）
- 上传与入口
  - 接入 react-dropzone，提供拖拽上传与进度提示
  - 统一“开始生成”主按钮与引导状态（空态/已配置态）
- 音高检测原型
  - Web Worker + Meyda/Essentia.js 的 Pitch/谱域分析

- 难度映射与乐谱生成
  - 规则：入门（单音/慢速）、普通（简单和弦/八分音符）、进阶（装饰音/切分）

- 导出与分享
  - 导出图片/简谱（html2canvas/MIDI），本地管理清单
  - 社交分享预览（OG 图生成）
- 无障碍与体验

  - 焦点样式与键盘导航；懒加载重型组件

## 里程碑 M2 详细需求
- 功能范围
  - 支持拖拽与点击选择上传本地音频文件
  - 显示上传状态（空态/拖拽中/上传中/成功/失败）
  - 展示文件信息（名称、类型、大小、时长、采样率等基础元数据）
  - 错误提示与恢复操作（重试/更换文件/清除文件）
- 文件校验
  - 类型白名单：audio/mpeg（.mp3）、audio/wav（.wav）；后续可扩展 .m4a/.aac
  - 大小限制：默认 ≤ 20MB（可在设置中调整预留），超限给出明确提示
  - 时长限制：默认 ≤ 10 分钟；过长文件提醒并建议裁剪
  - 尝试解析失败时提示“文件损坏或编码不兼容”，引导更换文件
- 解析与元数据
  - 使用 Web Audio API decodeAudioData 解析缓冲并获取 duration、sampleRate、channelCount
  - 提取基础峰值信息用于后续难度/节奏预估（简化版，非谱生成）
  - 解析过程放入 Web Worker（或队列），避免阻塞 UI
- 交互与 UI
  - Dropzone 组件：拖拽高亮、占位说明文案、支持键盘操作
  - 进度/状态提示：加载骨架、环形进度或线性进度条
  - 成功状态的文件卡片：显示基础元数据与“开始生成”入口
- 状态与持久化
  - 在 zustand store 保存当前选中文件的元数据与解析状态
  - 持久化仅保存元信息，不持久化音频二进制（节约空间与隐私）
- 安全与隐私
  - 仅处理本地文件，不上传；文件解析仅在浏览器内完成
  - 做好异常处理与资源释放（AudioBuffer/URL.createObjectURL）
- 性能与可用性
  - 大文件解析采用 Worker，主线程显示进度与可取消动作
  - 对低性能设备降低动画/特效；响应式布局保证移动端可用
- 测试与验收
  - 单测：文件类型/大小/时长校验、解析结果与错误分支
  - 组件测试：Dropzone 键鼠交互、状态切换与可访问性（aria/live region）
  - 集成测试：上传→解析→状态流转；覆盖率目标 ≥ 80%
  - 验收标准：在主流浏览器（Chromium/Firefox/Safari）正常上传与解析，状态与错误提示清晰
- 交付物
  - Dropzone 上传组件与解析管线（含 Worker）
  - Store 与类型定义更新、文档说明
  - 测试用例与构建通过的产物
